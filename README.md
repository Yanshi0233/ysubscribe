## 一、自我介绍

大家好，我是一名在校大学生，平时会订阅各种服务（视频、音乐、工具软件），但经常忘记续费日期，也不知道每月到底花了多少钱。这次全程用 Qoder 完成了开发和部署。

## 二、我的作品是什么

**一句话**：一个帮你管理所有订阅服务的网页工具，自动计算续费日期、统计月均支出、分类管理订阅，打开链接就能用，无需注册。

**五个核心功能**：

- 💰 **订阅管理** — 添加、编辑、删除订阅，记录名称、账号、费用、续费周期
- 📅 **智能提醒** — 自动计算下次续费日期，7 天内到期的订阅显示警告标识
- 📊 **支出统计** — 实时显示订阅总数、进行中/已取消数量、月均支出
- 🏷️ **分类管理** — 5 种分类（音乐/视频/工具/聊天/游戏），输入名称自动识别分类
- ☁️ **云端同步** — 支持 GitHub 仓库同步，多设备数据不丢失；也可导出 `.ysubscribe` 文件备份

## 三、为什么做

现在订阅制服务越来越多：

- 视频平台：Netflix、爱奇艺、B站大会员
- 音乐平台：Spotify、网易云音乐
- 工具软件：Notion、iCloud、GitHub
- 游戏平台：Steam、Xbox Game Pass

每个服务的续费日期都不一样，有的按月、有的按年、还有终身买断的。我经常遇到这些问题：

1. 忘记续费导致服务中断
2. 不知道每月订阅花了多少钱
3. 换了设备数据就丢了
4. 想取消某个订阅但找不到在哪里管理

市面上的记账工具太重，我只想找一个专门管理订阅的轻量工具，所以自己做了一个。

# 以下为原始技术文档

# 订阅管理器 (Subscription Manager)

一个轻量级的订阅管理工具，使用纯前端技术构建，可部署到 Qoder Sites。

## 功能特性

### 核心功能
- ✅ **管理订阅** - 查看所有订阅的详细信息
- ✅ **新增订阅** - 添加新的订阅服务
- ✅ **编辑订阅** - 修改现有订阅信息
- ✅ **停止续订** - 标记订阅为已取消状态
- ✅ **删除订阅** - 移除不需要的订阅记录
- ✅ **自动保存** - 使用 localStorage 持久化存储数据
- ✅ **导出功能** - 导出为 `.ysubscribe` 文件（JSON 格式）
- ✅ **导入功能** - 从 `.ysubscribe` 文件导入订阅数据

### 订阅信息
每个订阅包含：
- 订阅名称（如 Netflix、Spotify）
- 订阅账号（邮箱或用户名）
- 费用金额和货币类型
- 续费周期（每 X 天/月/年 或 终身）
- 订阅开始日期
- 下次续费日期（自动计算）
- 备注信息

### 界面特性
- 📊 统计面板 - 显示订阅总数、进行中、已取消数量和月均支出
- 🔍 搜索过滤 - 按名称或账号搜索，按状态过滤
- ⚠️ 续费提醒 - 7天内到期的订阅会显示警告标识
- 🎨 响应式设计 - 适配桌面和移动设备
- 🌈 现代化 UI - 渐变色彩和卡片布局

## 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和动画
- **JavaScript (ES6+)** - 交互逻辑
- **Bootstrap 5.3.2** - UI 框架
- **jQuery 3.7.1** - DOM 操作
- **Bootstrap Icons** - 图标库

## 数据格式

### .ysubscribe 文件结构

```json
{
  "version": "1.0",
  "exportedAt": "2024-01-15T10:30:00.000Z",
  "subscriptions": [
    {
      "id": "sub_1234567890_abc",
      "name": "Netflix",
      "account": "user@example.com",
      "currency": "¥",
      "price": 98.00,
      "cycle": {
        "type": "months",
        "value": 1
      },
      "startDate": "2024-01-01",
      "nextRenewalDate": "2024-02-01",
      "status": "active",
      "notes": "家庭套餐",
      "createdAt": "2024-01-01T00:00:00.000Z",
      "updatedAt": "2024-01-01T00:00:00.000Z"
    }
  ]
}
```

### 字段说明

- `id`: 唯一标识符
- `name`: 订阅名称
- `account`: 订阅账号
- `currency`: 货币符号（¥, $, €, £）
- `price`: 费用金额
- `cycle.type`: 周期类型（days, months, years, lifetime）
- `cycle.value`: 周期数值
- `startDate`: 开始日期
- `nextRenewalDate`: 下次续费日期（终身订阅为 null）
- `status`: 状态（active, cancelled）
- `notes`: 备注
- `createdAt`: 创建时间
- `updatedAt`: 更新时间

## 使用说明

### 添加订阅
1. 点击右上角"新增订阅"按钮
2. 填写订阅信息
3. 选择续费周期类型和数值
4. 设置开始日期
5. 点击"保存"

### 停止续订
1. 找到要取消的订阅卡片
2. 点击"停止续订"按钮
3. 订阅状态将变为"已取消"

### 导出数据
1. 点击"导出"按钮
2. 输入文件名（系统自动添加 .ysubscribe 后缀）
3. 点击"导出"下载文件

### 导入数据
1. 点击"导入"按钮
2. 选择 .ysubscribe 文件
3. 点击"导入"合并数据

## 浏览器兼容性

- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 79+

## 数据存储

所有数据存储在浏览器的 localStorage 中，键名为 `y_subscriptions`。

**注意**：清除浏览器数据会导致订阅信息丢失，建议定期导出备份。
